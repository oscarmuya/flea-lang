# Flea Programming Language

## Features
- Variables (let x = 5;)
```fl
let x = 5;
```
- Integers and maybe floats
- Arithmetic (+ - * /)
- Comparison (< > == !=)
- if/else
```fl
 if (a < b) {

 } else {

 }
```
- while loops
```fl
 while (true) {

 }
```
- print as a built-in statement (so you can see output without functions)
```fl
print x;
```
